# دليل تشغيل نظام Play Masr Pro على (Windows + Mac + عدة موبايلات أونلاين وأوفلاين)

## 1. التشغيل المباشر كمبرنامج مستقل أو عبر المتصفح:
- يمكنك فتح ملف `index.html` مباشرة على أي جهاز **Windows** أو **Mac** أو **موبايل (Android / iPhone)**، وسيعمل النظام بالكامل أونلاين وأوفلاين مع حفظ كافة البيانات تلقائياً.

## 2. ربط عدة موبايلات + ويندوز + ماك معاً في نفس اللحظة (حتى لو الإنترنت مقطوع!):
1. على جهاز الكمبيوتر الرئيسي بالصالة (Windows أو Mac)، تأكد من وجود برنامج Node.js ثم اضغط مرتين على:
   - **`START_WINDOWS.bat`** (لو جهازك ويندوز)
   - **`START_MAC.command`** (لو جهازك ماك)
2. ستظهر لك شاشة السيرفر وبها رابط الشبكة المحلية مثل: `http://192.168.1.100:3000`
3. افتح هذا الرابط من **أي عدد من الموبايلات** (موبايل الكاشير، موبايل الويتر، موبايل شاشة البار والمطبخ، موبايل المدير) أو أجهزة الماك والويندوز المتصلة بنفس الواي فاي.
4. أي أوردر أو تشغيل جهاز أو تعديل وقت يتم على أي موبايل سيسمّع في **نفس اللحظة** على كل الأجهزة الأخرى، سواء كان الإنترنت متصلاً أو مفصولاً تماماً!
